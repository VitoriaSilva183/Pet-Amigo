# 🐾 Pet Amigo

Site desenvolvido para um pet shop fictício chamado **Pet Amigo**, criado com HTML e CSS.

O projeto apresenta informações sobre o pet shop, seus serviços e produtos para cães e gatos.

## 📌 Sobre o projeto

O **Pet Amigo** nasceu em 2018 com o objetivo de oferecer um espaço limpo, seguro e acolhedor para os animais de estimação.

O site foi desenvolvido com uma estrutura simples e organizada, contendo três páginas principais:

* 🏠 **Início** — apresentação do Pet Amigo e dos serviços oferecidos.
* 🐶 **Sobre** — informações sobre o pet shop.
* ✂️ **Serviços** — apresentação dos serviços e produtos disponíveis.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3

## 📄 Páginas

### 🏠 Início

Apresenta o Pet Amigo e uma breve descrição dos serviços oferecidos, como banho e tosa e venda de produtos.

### 🐾 Sobre

Apresenta a história e o objetivo do Pet Amigo, destacando o cuidado com cães e gatos.

### ✂️ Serviços

A página apresenta os principais serviços e produtos:

* Banho
* Tosa
* Venda de ração
* Acessórios

## 🎨 Estilização

O site utiliza uma identidade visual baseada principalmente em tons de roxo. O CSS define o fundo da página, cabeçalho, menu de navegação, conteúdos, imagens e cards dos serviços.

## 🚀 Como executar

1. Baixe ou clone o projeto.
2. Mantenha os arquivos e pastas na mesma estrutura.
3. Abra o arquivo `index.html` em um navegador.
4. Navegue pelo menu para acessar as páginas **Início**, **Sobre** e **Serviços**.

## 🎯 Objetivo

Praticar os conceitos básicos de desenvolvimento web utilizando **HTML5 e CSS3**, trabalhando com estrutura de páginas, navegação, imagens, textos e estilização.
